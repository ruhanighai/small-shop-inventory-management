## Project Overview
An inventory tool for a small shop with stock records, low-stock alerts, and sales charts.

## Implemented Must-Haves
- [x] [Product stock CRUD
- [x] low-stock alerts
- [x] sales entry
- [x] sales chart]

## Key Learning Outcomes
- Manage CRUD data
- trigger alerts from thresholds
- chart sales data.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (or React / Vite / Next.js)
- **AI & Logic:** Generative AI prompt engineering, external APIs, state management
- **Deployment:** Vercel / Netlify / GitHub Pages (Deploy anywhere with zero restrictions!)

## How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/ruhanighai/small-shop-inventory-management.git
   ```
2. Navigate into the project directory:
   ```bash
   cd small-shop-inventory-management
   ```
3. Open `index.html` directly in your browser, or run your local dev server:
   ```bash
   # If using npm / Vite:
   npm install
   npm run dev
   ```
